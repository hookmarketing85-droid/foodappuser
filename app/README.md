# QuickBite Food Delivery User App

User-side food delivery web app MVP built with React + TypeScript + Vite.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Included user features

- Browse restaurants
- Search by name/cuisine/tag
- Filter by cuisine chips
- Sort by recommendation/rating/delivery time/delivery fee
- View restaurant-specific menu
- Add/remove items in cart
- Promo code support (`SAVE60`, `BITE10`)
- Checkout form and order confirmation
- Mobile responsive UI

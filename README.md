# Food Delivery User Web App

This repository now contains a user-facing food delivery web app (inspired by apps like Zomato and Foodpanda).

## Project location

- App source: `app/`

## Run locally

```bash
cd app
npm install
npm run dev
```

Then open the URL shown in the terminal.

## Features in current MVP

- Restaurant discovery with search, cuisine filters, and sorting
- Restaurant selection and menu browsing
- Add-to-cart with quantity updates
- Cart validation to prevent mixed-restaurant checkout
- Promo codes (`SAVE60`, `BITE10`)
- Checkout form and order confirmation screen
- Responsive layout for desktop and mobile
